# Student Marks Calculator

## Project Description
A beginner-friendly Python program that calculates a student's total marks, average, percentage, and grade.

## Features
- Accepts the student's name.
- Supports a dynamic number of subjects.
- Accepts maximum marks per subject.
- Validates subject count and maximum marks.
- Validates individual marks.
- Calculates total, average, and percentage.
- Assigns grades using conditional statements.

## Grade Criteria

| Percentage | Grade |
|---|---|
| 90 and above | A |
| 75–89.99 | B |
| 60–74.99 | C |
| 40–59.99 | D |
| Below 40 | F |

## How to Run

```bash
python marks_calculator.py
```
